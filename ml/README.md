# ML Module Directory

This directory contains the machine learning pipelines, research notebooks, datasets, and trained model artifacts for the AI Deficiency Risk Prediction module (Week 3+).

## Folder Layout
- `data/`: Raw and preprocessed CSV/Parquet datasets (git-ignored)
- `notebooks/`: Exploratory Data Analysis & training notebooks
- `scripts/`: Production model training & evaluation scripts
- `models/`: Trained model binaries (.pkl, .cbm, .joblib)
